---
title: Chat history
description: Review users' chat conversations for a deployment under Monitoring → Chat history.
---

Admins, and users with the [**Access chat history**][ref-custom-roles] custom
role permission, can view every user's chat conversations for a deployment. To
open them, go to **Monitoring → Chat history** in the deployment's sidebar.

It's possible to search specific chats by the first message content or chat UUID.
You can also filter the list by user type, creation date, and source — **Web**
(including Analytics Chat and the Excel/Google Sheets add-in panes), **MCP**,
**Slack**, **Scheduled**, or **API**.

Open a thread to read the conversation. Next to its **User** and **Created**
time, the thread shows its **Context window** usage, for example "34% of 200K
context", the same way the chat shows [context usage][ref-context-usage]. Use
it to debug slow or degraded answers. Threads with no reported usage, such as
older ones, don't show it.

To send chat turns to your own monitoring tools, use [chat history
export][ref-chat-history-export].
