---
title: Chats History
description: Admins, and users granted the Access chat history permission, can access users chat history through Admin → Chats History.
---

Admins, and users with the [**Access chat history**][ref-custom-roles] custom
role permission, can view every user's chat conversations for a deployment.

It's possible to search specific chats by the first message content or chat UUID.
You can also filter the list by user type, creation date, and source
(**Web**, **MCP**, **Slack**, **Scheduled**, or **API**).
