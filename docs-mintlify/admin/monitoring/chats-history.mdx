---
title: Chats History
description: Review users' chat conversations for a deployment under Admin → Chats History.
---

Admins, and users with the [**Access chat history**][ref-custom-roles] custom
role permission, can view every user's chat conversations for a deployment.

It's possible to search specific chats by the first message content or chat UUID.
You can also filter the list by user type, creation date, and source — **Web**
(including Analytics Chat and the Excel/Google Sheets add-in panes), **MCP**,
**Slack**, **Scheduled**, or **API**.

To send chat turns to your own monitoring tools, use [chat history
export][ref-chat-history-export].
