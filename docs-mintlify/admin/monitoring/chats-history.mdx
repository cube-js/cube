---
title: Chat history
description: Review users' chat conversations for a deployment under Monitoring → Chat history.
---

Admins, and users with the [**Access chat history**][ref-custom-roles] custom
role permission, can view every user's chat conversations for a deployment. To
open them, go to **Monitoring → Chat history** in the deployment's sidebar.

It's possible to search specific chats by the first message content or chat UUID.
You can also filter the list by user type, creation date, and source — **Web**
(including Analytics Chat and the Excel/Google Sheets add-in panes), **MCP**,
**Slack**, **Scheduled**, or **API**.

Open a thread to read the conversation. Next to its **User** and **Created**
time, the thread shows its **Context window** usage, for example "34% of 200K
context", the same way the chat shows [context usage][ref-context-usage]. Use
it to debug slow or degraded answers. Threads with no reported usage, such as
older ones, don't show it.

A chat started in a [published][ref-publish] or [embedded][ref-embedding]
dashboard's agent panel also shows its **Dashboard**. Admins see the
dashboard's title. Other users with **Access chat history** see its public id,
and so do admins when the dashboard was deleted or belongs to another
deployment. Older chats, started before Cube recorded the dashboard, don't
show it.

The [Chat History API][ref-chat-history-api] returns the same information as
`dashboard` (`publicId`, `title`) on each thread; `title` is `null` when the
dashboard isn't in the deployment. To list one dashboard's chats, filter
`GET /api/v1/deployments/{deploymentId}/chat-history/threads` by
`dashboardPublicId`. You can repeat the parameter up to 100 times.

To send chat turns to your own monitoring tools, use [chat history
export][ref-chat-history-export].

## Linking to a thread

To link to a thread from another tool, such as an alert built on [chat history
export][ref-chat-history-export], put its chat UUID in the URL:

```text
https://your-tenant.cubecloud.dev/d/<deployment_id>/chat-history/<chat_uuid>
```

`<chat_uuid>` is the `chatId` of an exported record or of a thread in the [Chat
History API][ref-chat-history-api], the same UUID as in the chat's own
`/chat/<chat_uuid>` URL. An exported record also carries the `deploymentId`.

The link opens the thread with its **Context window** usage. Opening it
requires the same access as **Monitoring → Chat history**.
