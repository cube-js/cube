[Push.ai](https://push.ai) is a business observability tool that helps teams
share metrics and other data insights in messaging tools, like Slack.

## Connect from Cube Cloud

Navigate to the [Integrations](/admin/connect-to-data/visualization-tools)
page, click **Connect to Cube**, and choose **Push.ai** to get
detailed instructions.

## Connect from Cube Core

You can connect a Cube deployment to Push.ai using the [REST (JSON) API](/reference/core-data-apis/rest-api).

## Connecting from Push.ai

### Adding an integration

Copy **REST (JSON) API endpoint** and **API secret** and paste them into Push.ai form for
creating the Cube data source:

<Frame>
  <img src="https://static.cube.dev/docs/admin/connect-to-data/visualization-tools/push-ai/06a814c2.png" />
</Frame>

### Defining metrics

After connecting to Cube, measures and dimensions need to be converted into
metrics. See [Push.ai documention](https://docs.push.ai/semantic-layer-integrations/cube#usage-notes)
for guidance.
