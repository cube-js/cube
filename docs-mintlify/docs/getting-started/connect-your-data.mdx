<Info>

If you don't have a data source to connect to, you can create a demo deployment to test all Cube features with demo data.

</Info>

Cube supports multiple warehouses and databases.

<Frame>
  <img src="https://static.cube.dev/docs/shared/deployment-wizard/database-picker.png" alt="Set up a database connection step of the deployment wizard with the grid of data sources" />
</Frame>

Once you select your data source, follow the instructions on the connection page.

  <img src="https://static.cube.dev/docs/shared/deployment-wizard/snowflake-connection.png" alt="Set up a database connection step of the deployment wizard with the Snowflake form: account URL, database, authentication method, role and warehouse" />
