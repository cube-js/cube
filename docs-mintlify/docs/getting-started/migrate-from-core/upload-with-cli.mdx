---
title: Import a local project to Cube Cloud with CLI
description: This guide walks you through creating a Cube deployment, connecting it to your database, and uploading an existing Cube project from your local machine with the Cube CLI.
---

## Step 1: Create a deployment

Click **Create deployment**. Then give it a name and select the cloud
provider and region of your choice.

  <img src="https://static.cube.dev/docs/shared/deployment-wizard/create-deployment-v2.png" alt="Create deployment step of the deployment wizard with the name, cloud platform and region" />
</Frame>

<Info>

Microsoft Azure is available on [Enterprise plan](https://cube.dev/pricing).

</Info>

## Step 2: Set up a Cube project

Click **Create**. You'll replace the new project with your own one in Step 5.

<Frame>
  <img src="https://static.cube.dev/docs/shared/deployment-wizard/set-up-cube-project-v2.png" alt="Set up Cube project step with the Create, Import from a GitHub repository and Import Git repository via SSH / HTTP options" />
</Frame>

## Step 3: Connect your database

Select your database and enter its credentials. Check the [connecting to
databases][ref-cloud-connecting-to-databases] guide for more details.

<Info>

Want to use a sample database instead? We also have a sample database where you
can try out Cube:

| -------- | ------------------ |
| Host     | `demo-db.cube.dev` |
| Port     | `5432`             |
| Database | `ecom`             |
| Username | `cube`             |
| Password | `12345`            |

</Info>

<Frame>
  <img src="https://static.cube.dev/docs/shared/deployment-wizard/postgres-connection-v2.png" alt="PostgreSQL connection form filled in with the sample database credentials" />
</Frame>

Click **Apply**. You'll upload your own data model in Step 5, so on the next step
click **Skip & deploy** instead of selecting tables. On the onboarding screen
that follows, click **Skip** and confirm.

<Frame>
  <img src="https://static.cube.dev/docs/shared/deployment-wizard/select-tables-v2.png" alt="Select tables for AI generation step with the Skip & deploy and Generate buttons" />
</Frame>

## Step 4: Switch the deployment to CLI deploys

Go to **Settings → Build & deploy**, select **Deploy with CLI**, and click
**Apply**.

<Frame>
  <img src="https://static.cube.dev/docs/shared/deployment-wizard/build-deploy-cli.png" alt="Deploy with section of the Build & deploy page with Deploy with CLI selected" />
</Frame>

## Step 5: Upload your Cube project

Use the [Cube CLI][ref-cli] to upload your project. Run the following commands
from your Cube project directory:

```bash
cube login --url https://TENANT.cubecloud.dev
cube deployments list  # find the deployment ID
cube deploy <DEPLOYMENT_ID> --directory .
```

<Note>

The `cubejs-cli deploy` command is deprecated. It authenticates with a deploy
token: `npx cubejs-cli deploy --token <TOKEN>`. Use `cube deploy` instead.

</Note>

## Step 6: Try out Cube

The **Status** page shows the build and the deployment's resources:

<Frame>
  <img src="https://static.cube.dev/docs/shared/deployment-wizard/status-page-v2.png" alt="Status page of a new deployment with its integrations, resources and activity log" />
</Frame>

Now you can navigate to [the Playground][ref-cloud-playground] to try out your
queries or connect your application to the Cube API.
