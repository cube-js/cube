---
title: Scatter
description: Plot two measures against each other to find correlations, clusters, and outliers.
---

Scatter charts plot individual data points using two measures as X and Y coordinates. Use them to explore relationships between measures, identify clusters, and spot outliers across a population of entities.

A scatter chart uses the same Fields and Style tabs as bar, line, and area charts. It is a point chart with a measure on the X axis.

## Variants

### Basic scatter

Two measures on the X and Y axes. Each row in your result set becomes one point.

### With color grouping

Pick a dimension in **Break down by** for a measure to assign each point a color by category. Use this to compare how different groups distribute across the same two measures.

### With size encoding

Pick a third measure in the **Size** section to scale each point's radius by value. Use this to encode a third variable without adding a new axis.

### Multiple measures

Add more measures to plot several point clouds against one shared X axis. Each measure gets its own color and shape. Put a measure on the **Left** or **Right** Y axis to plot it on its own scale.

## Fields tab

To build a scatter chart, pick a measure in the **Other member** section. This section holds the X axis on bar, line, and area charts too. Then pick the Y measures in the **Measure** sections.

With a measure on X, the Fields tab changes:

- The **Mark** dropdown of each measure is fixed at **Point**. Bar, line, and area marks are not available.
- Orientation, **Sort**, and **Time unit** are hidden.
- The **Points** and **Size** sections appear.

If you put a dimension back on X, the measures stay as points. You can change their mark again.

### Points

**One point per** sets what each point stands for. The default is **Each row**: the chart draws one point per row of the query result. To draw one point per value of a dimension instead, pick one or more dimensions. The chart then aggregates the measures for each combination of the picked values.

### Size

Pick a measure in the **Size** section to scale each point's radius by its value. The size measure is added to the tooltip automatically. Clear the selection to draw all points at one size.

## Style tab

| Section | Settings |
|---|---|
| **X-Axis** | With a measure on X, the same settings as the Y axis: log scale, **Min / Max**, and label format. See [Axes](/docs/explore-analyze/charts/configuration/axes). |
| Per-measure chip row | **Shape** of the points (circle, square, triangle, or **Auto**) and **Trend line**. |
| **Size** | Appears only when a size measure is picked. Toggle the size legend and set **Radius min** and **Radius max** in pixels. The smallest value is drawn at **Radius min**, the largest at **Radius max**. |

{/* Screenshot: Style tab Size section — legend toggle, Radius min and Radius max inputs. Place inline, 50% width, right-aligned. (hidden — replace this comment with <Frame><img src="..." /></Frame> when image is ready) */}

A log scale is not available on an axis that has a zero or a negative value.

## Tooltips

All mapped fields appear in the tooltip by default. Add or remove fields in the **Tooltips** section of the Fields tab.

See [Tooltips](/docs/explore-analyze/charts/configuration/tooltips) for details.
