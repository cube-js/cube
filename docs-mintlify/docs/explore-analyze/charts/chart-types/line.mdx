Line charts connect data points with a continuous line. Use them when the direction and rate of change matter — trends over time, trajectories of multiple series, or any ordered dimension where continuity is meaningful.

## Reference lines

Add a horizontal reference line from the **⋮** menu of the **Y axis** section of the Style tab. A new line starts at the axis's current maximum. Set the value, label, color, line style (solid, dashed, or dotted), and width. Each line also takes a [label position](/docs/explore-analyze/charts/configuration/axes#reference-line-labels). Multiple reference lines are supported. A line can also sit at a [computed value](/docs/explore-analyze/charts/configuration/axes#computed-reference-lines), such as the average, and a [reference band](/docs/explore-analyze/charts/configuration/axes#reference-bands) shades a range.

On the X axis, add a vertical line the same way from the **X axis** section, for example at a date to mark a launch.

## Axis behavior

The X axis depends on the dimension:

- **Time dimensions** get a temporal axis: continuous, time-aware, and not constrained to the result set.
- **Numeric dimensions** get a linear axis: points are spaced by value, so a gap between values (for example, 2 and 5) shows on the axis.
- **Other dimensions** get an ordinal axis: values are evenly spaced and sorted in ascending order by default.
- **A line combined with bars** uses an ordinal axis for numeric dimensions too, since bars need evenly spaced slots. Numeric values sort in ascending numeric order by default.

On an ordinal axis, pick another **Sort** for the dimension on the Fields tab to change the order, such as **None** to keep the results table order.

A missing measure value breaks the line. On a linear or temporal axis, X values absent from the results are bridged by a straight segment.

## Combining with bars

To layer a line on top of a bar chart, add a second series to the Y axis, set its mark type to **Line** in [series configuration](/docs/explore-analyze/charts/configuration/series-configuration), and assign it to the right Y axis for a dual-axis layout.
