KPI tiles highlight important metrics and key performance indicators. Rather than a single fixed layout, KPIs are **row-based and composable** — you build the tile by stacking blocks of different types, each configured independently.

## Getting started

The KPI visualization starts with a **Number** block that shows the first row of your result for the first numeric column.

Click **Design** to open the chart builder. It lists every block of the tile as a card, in the order the blocks appear, with each block's settings on its **Data** and **Style** tabs. To add a block, click **Add block** below the cards and choose the block type.

Reorder blocks by dragging the handle on the left side of a card's title. Remove a block with the **×** button on the right side of its title.

## Block types

### Number

Displays a single value from your query result.

| Setting | Description |
|---|---|
| **Field** | The measure or dimension to display |
| **Row** | Which row of the result to read from |
| **Format** | Number formatting (currency, percent, etc.) |
| **Font size / color** | Text appearance |
| **Alignment** | Left, center, or right |

### Comparison

Displays a current value alongside a previous value with a calculated difference. Use this to show period-over-period change or target vs. actual.

| Setting | Description |
|---|---|
| **Current field / row** | The primary value |
| **Previous field / row** | The value to compare against — can be a different column or a different row from the same column |
| **Difference format** | Absolute, percentage, or both |
| **Positive color / Negative color** | Colors applied based on whether the change is positive or negative |

To compare to a static goal, add a column to your query that always returns the same number (e.g. a calculated field with a constant), then select it as the **Previous** field.

### Progress bar

Shows a value relative to a target as a progress bar or circle. Useful for goal tracking.

| Setting | Description |
|---|---|
| **Value field / row** | The current progress value |
| **Target field / row** | The goal or maximum value |
| **Style** | Bar or circle |
| **Color** | Fill color for the progress indicator |

<Tip>
To compare against a static number like a quarterly goal, add a calculated field that always returns that number and use it as the **Target** field.
</Tip>

### Sparkline

Renders a compact trend chart — either a bar or line — within the KPI tile. Use this to show the trend behind a value.

Above the chart, the block shows a headline value. By default, it's the series measure from the first row of the query result. Turn off **Headline uses sparkline measure** and pick a **Headline column** to show a different measure. If you turn it off and leave **Headline column** empty, the headline shows the last point of the trend.

| Setting | Description |
|---|---|
| **Series measure** | The measure to plot |
| **Headline uses sparkline measure** | Shows the series measure in the headline. Turn it off to pick a different measure |
| **Headline column** | The measure the headline shows when **Headline uses sparkline measure** is off |
| **Headline row** | Which row of the query result the headline reads: 1st or 2nd, in the order the query returns rows |
| **Show value** | Shows or hides the headline value |
| **Series dimension** | The dimension to use as the X axis (typically a time dimension) |
| **Chart type** | Bar or line |
| **Height / Width** | Dimensions of the sparkline in the tile |
| **Max points** | Limits the number of data points rendered |
| **Colors** | Line/fill colors |

### HTML

A free-form block rendered inside the KPI tile. It accepts Markdown and HTML with CSS styling, so use it for titles, headings and descriptions, as well as custom layouts that go beyond what the other block types support. For complex layouts, consider the [Custom visualization](/docs/explore-analyze/charts/custom) instead.

## Layout controls

KPI tiles have a layout panel that controls how blocks are arranged:

| Setting | Description |
|---|---|
| **Direction** | Row (blocks side-by-side) or Column (blocks stacked vertically) |
| **Alignment** | How blocks align on the cross axis |
| **Justify** | How blocks are distributed along the main axis |
| **Gap** | Spacing between blocks |
| **Wrap** | Whether blocks wrap to a new line when the tile is narrow |

## Drill down

Clicking the value of a **Number** block that shows a measure, or the headline value of a **Sparkline** block, opens the [value menu](/docs/explore-analyze/charts#clicking-a-value), as clicking a measure cell does in a [table](/docs/explore-analyze/charts/chart-types/table#cell-menu). Choose **Drill down** there to open the rows behind the value. **Drill down** is offered when the measure has [`drill_members`](/reference/data-modeling/measures#drill_members) defined in the data model. Other blocks don't open the value menu. On a published dashboard with [comments](/docs/explore-analyze/dashboards/comments#comments-on-a-data-point), a click elsewhere on the KPI opens a menu with only **Comment on whole chart**.

The menu opens in workbooks and on dashboards, including published and embedded ones. While you edit a dashboard, a click on a KPI value doesn't open the menu, because the tile can be dragged.

## Converting to raw Markdown

If you need customization beyond what the block builder supports, you can convert the KPI visualization directly to Markdown by clicking on the Markdown visualization option.

<Warning>
Converting to Markdown is a one-way operation. If you do this accidentally, use the undo button to revert.
</Warning>
