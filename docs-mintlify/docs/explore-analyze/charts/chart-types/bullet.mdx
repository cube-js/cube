---
title: Bullet
description: Compare a measure to its target against qualitative ranges, such as revenue against quota by region.
---

A bullet chart draws one bar per category, a marker for the target, and shaded ranges behind them,
such as *Poor*, *Satisfactory* and *Good*. It shows in a compact space whether each value meets its
target and how far it is from the next range.

In Cube, you build a bullet chart from a [bar chart](/docs/explore-analyze/charts/chart-types/bar):
the target is a second measure drawn as points, or a reference line, and the ranges are
[reference bands](/docs/explore-analyze/charts/configuration/axes#reference-bands).

## Build a bullet chart

1. Build a query with a dimension, such as a region, the measure to compare, such as revenue, and
   the target measure, such as the revenue quota.
2. Pick the **Bar** chart type. On the Fields tab, set **Orientation** to **Horizontal**.
3. On the Fields tab, open the mark type menu next to the target measure and choose **Point**. Each
   category gets a marker at its own target. The chart type now reads **Composite**, since the
   chart mixes bars and points. See
   [Series configuration](/docs/explore-analyze/charts/configuration/series-configuration#mark-type-override).
4. Add the ranges. In the Style tab, open the **⋮** menu of the **X-axis** section, which holds the
   measures on a horizontal chart, and choose **Add reference band**. Repeat once per range.
5. Click **Band options** in each band row and set **From** and **To** to **Percent**, so each
   category gets its own ranges from its own target
   ([bands for each bar](/docs/explore-analyze/charts/configuration/axes#bands-for-each-bar)).
   **Computed from** switches to the target measure. Set the percentages to 0–60% for *Poor*,
   60–80% for *Satisfactory* and 80–100% for *Good*. The bars get narrower, so the ranges show
   around them.
6. Click each band's color swatch to give the bands shades from light to dark. Optionally, set
   each band's **Label** in **Band options**, for example *Poor*, *Satisfactory* and *Good*.

To use the same ranges for every category, type the **From** and **To** values in each band row
instead, for example 0–8,000, 8,000–14,000 and 14,000–22,000, and click each band's color swatch
to give the bands shades from light to dark.

If every category has the same target, leave the target measure out of the query, skip step 3,
and add a [reference line](/docs/explore-analyze/charts/configuration/axes#reference-lines) at the
target value instead. Set the ranges as numbers, as above: without a target measure, a **Percent**
edge would be computed from each bar's own value.

To show one value with its target and ranges, such as a single KPI, leave out the dimension. The
chart draws one bar.

<Tip>
Each band draws a line on its edges and prints its range in its label. For a cleaner chart, turn
off **Show edges** and **Show value** in **Band options**, so only the shading and any band labels you
set mark the ranges.
</Tip>

## Limitations

- There is no single control for several ranges. Each range is a band of its own, with its own
  label and color.
- A band's label prints outside the band, past one of its edges, not inside the range it names.
- Ranges set as a percentage of each category's target need a chart without a breakdown.
- The target marker is a point: a circle, a square, or a triangle. There is no thin tick mark.
- With ranges set as numbers, the bars keep their usual width, so the bands show around the bars
  rather than as a wider strip behind a narrow bar.
