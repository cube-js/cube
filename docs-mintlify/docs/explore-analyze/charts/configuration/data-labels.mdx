Data labels show the aggregate total value above each full stack on stacked bar charts. They let users read exact values without cross-referencing the Y axis.

## Enabling data labels

Open the **Style** tab and enable the **Data labels** toggle.

## Label settings

| Setting | Description |
|---|---|
| **Format** | **Auto** by default: each label uses its measure's number format from the data model, such as a percentage. Pick **Number**, **Percentage** or **Currency** to override it, and **Auto** to go back |
| **Font size** | Size of the label text |
| **Position** | Outside end, Inside end, Inside center, or Inside base |
