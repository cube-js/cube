The **Axes** section in the Style tab controls the appearance and behavior of the X axis and Y axis (or left and right Y axes in dual-axis charts). Most axis settings are available for all Vega-based chart types (bar, line, area, scatter, heatmap).

## X axis

| Setting | Description |
|---|---|
| **Show axis** | Toggle the X axis on or off |
| **Title** | Custom axis label — leave blank to hide the axis title |
| **Grid lines** | Toggle grid lines perpendicular to the X axis |
| **Labels** | Toggle axis tick labels |
| **Label angle** | Rotate axis labels (useful for long category names) |
| **Label format** | Number or date format applied to axis labels |

## Y axis (left)

| Setting | Description |
|---|---|
| **Show axis** | Toggle the Y axis on or off |
| **Title** | Custom axis label |
| **Grid lines** | Toggle horizontal grid lines |
| **Labels** | Toggle axis tick labels |
| **Label format** | Number format applied to axis labels (e.g. `$,.0f` for currency) |
| **Min / Max** | Override the axis scale minimum and maximum values |

## Dual Y axis (right axis)

Add a second Y axis on the right side of the chart to plot a series on a different scale. This is useful for combining measures with different units or magnitudes — for example, showing order count on the left axis and average order value on the right.

To use the right axis:
1. In the **Series configuration** for a specific series, change the **Y axis** assignment from **Left** to **Right**.
2. The right axis settings appear in the Style tab — configure its title, labels, and scale independently from the left axis.

## Reference lines

Add reference lines to mark a target, threshold, or benchmark value. A line on a measure axis runs
across the chart at a fixed or computed value. A line on the X axis of a time series runs vertically, for
example to mark a launch date.

To add a reference line:
1. In the Style tab, open the **⋮** menu of an axis section and choose **Add reference line**.
2. The line starts at the axis's current maximum. Change the value in the row to move it. Clear the
   value to keep the line at the maximum as the data changes.
3. Click the color swatch to change the line's color and its label background.
4. Click **Line options** to set the line at a [computed value](#computed-reference-lines), name
   the line, set the line style (solid, dashed, or dotted), the line width, and the label position.

A new line is named *Reference*, then *Reference 2*, and so on. Its name and value print on the
chart. Turn off **Show value** in **Line options** to print the name only.

Each reference line is one row in its axis section, and you can add several to the same axis. To
remove one, open the row's **⋮** menu and choose **Remove**. The axis section's **Reset** button
also returns every line's color, width, style, and label position, and every
[band's](#reference-bands) color and label position, to the defaults. Everything else stays,
including the values, the labels, and a band's edge style and width.

### Computed reference lines

A line on a measure axis can follow the data instead of a fixed value. In **Line options**, change
**Line at** from **Number** to one of these values:

| Value | The line sits at |
|---|---|
| **Average** | The mean of the measure |
| **Median** | The median of the measure |
| **Minimum** | The smallest value of the measure |
| **Maximum** | The largest value of the measure |
| **Percentile** | The percentile you type next to it, from 0 to 100 (90 by default) |

Each option shows the value it computes to, so you can compare them before you choose. The value
is computed from the points the chart draws. On a stacked chart, it is computed from the stack
totals. The line moves when the data changes, for example after a filter.

When the axis has more than one measure, choose which one in **Computed from**. If you remove that
measure from the axis, the row shows a warning and *This measure is no longer on this axis*. Choose
another measure in **Computed from** to fix the line.

<Note>
Computed values are not available on a 100% stacked chart, because it draws shares, not values.
</Note>

### Reference line labels

A new line prints its default name and value. Rename it in **Label** in **Line options** so the
reader knows what it marks, for example `Target 18k`.

Place the text with **Label position** in **Line options**. Pick one
option from each row, for six positions in total. For a line across the chart, on a measure axis:

| Direction | Options | Description |
|---|---|---|
| **Horizontal** | Start / Middle / End | Where along the line the text sits |
| **Vertical** | Above / Below | Which side of the line the text sits on |

New labels start at **End** and **Above** — on a line across the chart, that is the right end of
the line, clear of the bars. The label background takes the line's color, so the label always reads
as part of that line. An empty **Label** prints no name. Clear the label and turn off
**Show value** to remove the text and keep the line.

On a vertical line, the label sits halfway up the chart. **Start** puts it to the right of the
line, **Middle** centers it on the line, and **End** puts it to the left. **Above** and **Below**
put it just above or just below that halfway point.

<Tip>
On a line across the chart, a label near the top or bottom edge of the plot flips to the other
side of the line automatically, so the text stays inside the chart area.
</Tip>

<Note>
On a chart with a second Y axis, each side has its own reference lines and bands, drawn against
that side's scale.
</Note>

### Reference bands

A reference band shades a range of the chart, for example a target range or a promotion period.
A band on a measure axis runs across the chart. A band on a numeric or time X axis runs vertically.
Category axes do not have bands.

To add a reference band:
1. In the Style tab, open the **⋮** menu of an axis section and choose **Add reference band**.
2. Set the range in the row:
   - On a measure axis, type the **From** and **To** values. An empty value follows the axis's
     minimum or maximum, so a new band covers the full range of the data.
   - On a numeric X axis, type the **From** and **To** values. A new band covers the first to the
     last value in the data.
   - On a time X axis, pick the dates. A new band covers the first to the last date in the data.
3. Click the color swatch to change the band's color.
4. Click **Band options** to change the band.

**Band options** has these settings:

| Setting | Description |
|---|---|
| **From** / **To** | On a measure axis, a number or a computed value: **Average**, **Median**, **Minimum**, **Maximum**, or **Percentile**. For example, shade the range from the 25th to the 75th percentile. |
| **Computed from** | The measure that computed values use, when the axis has more than one |
| **Label** | The band's name. A new band is named *Band*, then *Band 2*, and so on. |
| **Show value** | Print the band's range in the label. On by default. |
| **Show edges** | Draw a line on each edge of the band. On by default. |
| Line style, width, and label position | The same settings as for a [reference line](#reference-line-labels). The line style and width apply to the edges. |

To change a line into a band, open the line row's **⋮** menu and choose **Convert to band**. The
line's value becomes the **From** edge. On a measure axis, the **To** edge is the **Average**, or
the 90th percentile when the line is already at the **Average** or **Median**. On a time axis, the
band covers 7 days. Lines on a category axis cannot become bands.

To change a band into two lines, one for each edge, open the band row's **⋮** menu and choose
**Split into lines**.

<Note>
A date band shows only when the axis is a time axis. On a bar chart that draws the dates as
categories, the band stays in the Style tab but does not show on the chart.
</Note>

<Tip>
You can also ask the AI agent in chat to add a reference line at a computed value, or a band for a
target range, for example "add a band for the 15k to 20k target".
</Tip>
