Every tab in a Cube workbook has a chart panel. Once your query returns results, switch to the chart panel to pick a visualization type and configure how the data is displayed — from a simple bar chart to a composable KPI tile or a fully custom Vega-Lite spec.

## Chart types

Cube has built-in support for bar, line, area, pie, scatter, heatmap, KPI, map, boxplot, and more. See the [chart types overview](/docs/explore-analyze/charts/chart-types) for a full list and guidance on which type fits which data shape.

### Selecting a chart type

Chart type icons at the top of the chart panel let you quickly switch between common layouts — grouped vs. stacked bars, line vs. area, table vs. chart view — without opening the full configuration panel.

When you run a query on a new tab, Cube shows the chart type picker rather than picking for you. It outlines the type that best fits your query and labels it **Recommended** — see [Recommended chart type](/docs/explore-analyze/charts/chart-types#recommended-chart-type) — but choosing one is always your action. Any manual configuration you apply is preserved when you change query fields.

### Resetting chart settings

Sections of the configuration panel — fields, series, pivot, column widths — each carry their own **Reset** control, which clears that section back to its defaults. Resetting does not change the chart type you picked.

## Generate charts with AI

Describe the visualization you want in plain language — for example, _"show this as a stacked bar grouped by status"_ — and the AI agent will build and configure it. You can also let the agent auto-suggest the best chart for your query results. This is a separate mechanism from the **Recommended** outline in the chart type picker: the agent writes a Vega-Lite spec and applies it, while the recommendation only marks a built-in type for you to pick.

Charts generated by the AI are written as [Vega-Lite v5](https://vega.github.io/vega-lite/) specs and can be further edited in the [custom visualization](/docs/explore-analyze/charts/custom) spec editor.

## Configure charts

Adjust the appearance of any chart through the configuration panel:

- **[Color and stacking](/docs/explore-analyze/charts/configuration/color-and-stacking)** — Color palettes, series coloring, and stacking behavior
- **[Series configuration](/docs/explore-analyze/charts/configuration/series-configuration)** — Per-series mark type, color, and display options
- **[Series mapping](/docs/explore-analyze/charts/configuration/series-mapping)** — Assign query fields to chart channels (X, Y, color, size)
- **[Axes](/docs/explore-analyze/charts/configuration/axes)** — Axis titles, grid lines, scale, reference lines, and reference bands
- **[Tooltips](/docs/explore-analyze/charts/configuration/tooltips)** — Fields shown on hover
- **[Data labels](/docs/explore-analyze/charts/configuration/data-labels)** — Values displayed directly on chart marks

## Clicking a value

A click on a value in a chart opens the same menu as a measure cell in a [table](/docs/explore-analyze/charts/chart-types/table#cell-menu). You can click a bar, a line or area point, a pie slice, a scatter point, a heatmap cell, a funnel stage, a box, a Sankey ribbon, a map marker, or the value of a KPI chart's **Number** or **Sparkline** block. The menu opens in workbooks and on dashboards: in the dashboard builder, on published dashboards and on embedded ones. While you edit a dashboard, a click on a KPI value doesn't open the menu. A click alone doesn't drill down. Choose **Drill down** in the menu instead.

The menu lists, from top to bottom:

- A title that names the clicked value: each dimension's title and value, then the measure's title and formatted value.
- **Open in** and the target dashboard's title, on a chart with a [drill-through](/docs/explore-analyze/dashboards/drill-through).
- **Drill down**, when the measure has [`drill_members`](/reference/data-modeling/measures#drill_members) defined, and **Copy value**, which copies the raw (unformatted) value.
- The [cross-filter](/docs/explore-analyze/dashboards/cross-filtering) items: **Filter dashboard by this point**, **Narrow filter to this point** and **Reset this filter**.
- **Comment on this point** and **Comment on whole chart**, on a published dashboard with [comments](/docs/explore-analyze/dashboards/comments#comments-on-a-data-point) on.

Each item appears only where it applies. Some values get a shorter menu:

- The **Other** slice of a pie chart, and a Sankey ribbon that touches a grouped **Other** node, offer only **Copy value**. They cover several members, so they have no title and no **Drill down**.
- A KPI total with no dimension has no title.
- A region of a region map offers the drill-through, comment and cross-filter items only, with no title and no **Copy value**.

Dragging across a chart's axis [selects a range](/docs/explore-analyze/dashboards/cross-filtering#selecting-a-range), and the menu then has one item, **Filter dashboard by these points**. Cmd/Ctrl+click [adds a value](/docs/explore-analyze/dashboards/cross-filtering#adding-and-removing-values) to the chart's cross-filter without opening the menu.

An item that can't run on the value you clicked, such as **Filter dashboard by this point** on an empty value, is greyed out, with the reason under its label, so you can read it on a touch screen and from the keyboard too.

### Opening the menu from the keyboard

The menu opens from the keyboard wherever a click opens it:

- **Tables.** Move to a cell with <kbd>Tab</kbd> and the arrow keys, then press <kbd>Shift</kbd>+<kbd>F10</kbd> or the context-menu key. The cell's menu opens at the cell, and <kbd>Esc</kbd> closes it and puts the focus back on the cell. The keys work the same on a cell you clicked, once <kbd>Esc</kbd> has closed the menu the click opened. <kbd>Cmd</kbd>/<kbd>Ctrl</kbd>+<kbd>C</kbd> still copies the cell.
- **Charts and maps.** A chart whose click opens the menu is one <kbd>Tab</kbd> stop, announced as "Use the arrow keys to move between points, and Enter or Shift+F10 to open a point's actions." On a chart, <kbd>←</kbd> and <kbd>→</kbd> step through the points in sight from left to right, and <kbd>↑</kbd> and <kbd>↓</kbd> to the nearest point above or below at the same position, such as another series. On a map, the arrow keys step through the markers, or the regions of a region map, from west to east and from north to south. The focused point shows its tooltip, where the chart has one, and <kbd>Enter</kbd>, <kbd>Shift</kbd>+<kbd>F10</kbd> or the context-menu key does what a click on it does: it opens the menu at the point. <kbd>Esc</kbd> leaves the point. A chart that draws no point is no <kbd>Tab</kbd> stop.

## Custom visualizations

When the built-in chart types don't cover your use case, write a raw [Vega-Lite spec](/docs/explore-analyze/charts/custom) or use an HTML template with Handlebars. Both options give you complete control over the rendered output.
